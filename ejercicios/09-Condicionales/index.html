Condicionales

Las estructuras condicionales permiten que un programa tome decisiones: ejecutar un bloque de código u otro según se cumpla o no una condición.

Una condición es cualquier expresión que JavaScript pueda evaluar como verdadera (true) o falsa (false), normalmente construida con operadores de comparación y operadores lógicos.

JavaScript ofrece varias formas de escribir condiciones: if, else if y else, el operador ternario, switch y los operadores lógicos para asignar valores por defecto.

if, else if y else

  • if: ejecuta el bloque solo si la condición se cumple. 
    let edad = 20;
if (edad >= 18) {
    console.log('Eres mayor de edad');
}
  • else: bloque alternativo que se ejecuta cuando la condición no se cumple. 
    if (edad >= 18) {
    console.log('Puedes votar');
} else {
    console.log('Todavía no puedes votar');
}
  • else if: encadena varias condiciones. Se evalúan en orden y solo se ejecuta la primera que se cumple, así que el orden importa. 
    let nota = 7.5;
if (nota < 5) {
    console.log('Suspenso');
} else if (nota < 7) {
    console.log('Aprobado');
} else if (nota < 9) {
    console.log('Notable');
} else {
    console.log('Sobresaliente');
}
// Muestra 'Notable'
  • Usa siempre llaves: sin ellas, el if solo afecta a la primera línea, lo que provoca errores difíciles de ver. 
    if (edad >= 18)
    console.log('Mayor de edad');
    console.log('Esta línea se ejecuta SIEMPRE');

Construir condiciones

  • Operadores de comparación: >, <, >=, <=, === (igual) y !== (distinto). 
    console.log(5 > 3);    // true
console.log(5 !== 5);  // false
  • === frente a ==: === compara valor y tipo; == convierte los tipos antes de comparar y da resultados inesperados. Usa siempre === y !==. 
    console.log(5 == '5');   // true  (convierte el string a número)
console.log(5 === '5');  // false (número frente a string)
console.log(0 == '');    // true  ¡sorpresa!
  • Operadores lógicos: && (y) exige que se cumplan todas las condiciones, || (o) que se cumpla al menos una, y ! (no) invierte el resultado. 
    let tieneEntrada = true;
if (edad >= 18 && tieneEntrada) {
    console.log('Puedes pasar al concierto');
}
if (!tieneEntrada) {
    console.log('Compra una entrada');
}
  • Rangos: para comprobar si un valor está entre dos límites hay que escribir las dos comparaciones. La forma matemática 18 <= edad <= 65 no funciona en JavaScript. 
    if (edad >= 18 && edad <= 65) {
    console.log('Edad laboral');
}

Truthy y falsy

  • Conversión a booleano: en una condición, JavaScript convierte cualquier valor a true o false. Solo hay seis valores falsy: false, 0, '' (texto vacío), null, undefined y NaN. Todos los demás son truthy. 
    let nombre = '';
if (nombre) {
    console.log(`Hola, ${nombre}`);
} else {
    console.log('No has escrito tu nombre'); // se ejecuta este
}
  • Casos que confunden: el texto '0', el texto 'false', un array vacío [] y un objeto vacío {} son truthy. 
    let carrito = [];
if (carrito) { }            // se cumple: [] es truthy
if (carrito.length > 0) { } // así se comprueba si tiene elementos

Operador ternario

  • condición ? valorSiTrue : valorSiFalse: forma abreviada de un if...else que devuelve un valor. Es útil para asignaciones sencillas. 
    let edad = 15;
let mensaje = edad >= 18 ? 'Mayor de edad' : 'Menor de edad';
console.log(`Tienes ${edad} años: ${mensaje}`);
  • Ternarios anidados: son posibles, pero con más de dos niveles se vuelven difíciles de leer. En ese caso es mejor un if...else if. 
    let signo = n > 0 ? 'Positivo' : n < 0 ? 'Negativo' : 'Cero';

switch

  • switch: compara un valor con varios casos posibles. Es más claro que una cadena de else if cuando se compara la misma variable con valores concretos. 
    let semaforo = 'ámbar';
switch (semaforo) {
    case 'verde':
        console.log('Adelante');
        break;
    case 'ámbar':
        console.log('Precaución');
        break;
    case 'rojo':
        console.log('Alto');
        break;
    default:
        console.log('Color no válido');
}
  • break: termina el switch. Si se olvida, la ejecución continúa en el siguiente case aunque no coincida.
  • default: se ejecuta cuando ningún case coincide. Es opcional, pero conviene incluirlo para controlar los valores no esperados.
  • Agrupar casos: varios case seguidos sin código comparten el mismo bloque. 
    switch (dia) {
    case 'sábado':
    case 'domingo':
        console.log('Fin de semana');
        break;
    default:
        console.log('Laborable');
}
  • Comparación estricta: switch compara con ===, así que '1' no coincide con case 1.

Valores por defecto y propiedades opcionales

  • || (OR): devuelve el primer valor truthy. Sirve para dar un valor por defecto, pero también lo aplica cuando el valor es 0 o ''. 
    let volumen = 0;
let resultado = volumen || 50; // 50: se pierde el 0
  • ?? (coalescencia nula): solo usa el valor por defecto si el valor es null o undefined. Es la opción recomendada para valores por defecto. 
    let volumen = 0;
let resultado = volumen ?? 50; // 0: se respeta el valor
  • ?. (encadenamiento opcional): accede a una propiedad solo si lo anterior existe; si no, devuelve undefined en lugar de lanzar un error. Combinado con ?? evita muchos if. 
    let usuario = { nombre: 'Ana' };
console.log(usuario.direccion.ciudad);  // TypeError
console.log(usuario.direccion?.ciudad); // undefined
console.log(usuario.direccion?.ciudad ?? 'Desconocida'); // 'Desconocida'
  • && para ejecutar si se cumple: la parte de la derecha solo se evalúa si la izquierda es truthy. 
    let esAdmin = true;
esAdmin && console.log('Mostrando panel de administración');

Buenas prácticas

  • Cláusulas de guarda: dentro de una función, comprueba primero los casos no válidos y sal con return. Así se evitan if anidados. 
    function precioEntrada(edad) {
    if (edad < 0) {
        return 'Edad no válida';
    }
    return edad < 12 ? 5 : 9;
}
  • Objetos como tabla de búsqueda: cuando cada caso solo devuelve un valor, un objeto es más corto que un switch. 
    const COLORES = { verde: 'Adelante', ámbar: 'Precaución', rojo: 'Alto' };
console.log(COLORES[semaforo] ?? 'Color no válido');
  • Condiciones legibles: si una condición es larga, guárdala en una variable con un nombre que explique qué comprueba. 
    const puedeConducir = edad >= 18 && tieneCarnet && !estaSancionado;
if (puedeConducir) {
    console.log('Buen viaje');
}

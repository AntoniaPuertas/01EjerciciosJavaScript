Bucles

Un bucle repite un bloque de código mientras se cumpla una condición. Sirve para no escribir lo mismo muchas veces: mostrar los números del 1 al 100, recorrer todos los elementos de un array o pedir un dato hasta que sea válido.

Cada repetición se llama iteración o vuelta. JavaScript tiene varios tipos de bucle y cada uno encaja mejor en una situación distinta.

for

  • Estructura: tiene tres partes separadas por punto y coma: la inicialización (se ejecuta una vez al principio), la condición (se comprueba antes de cada vuelta) y la actualización (se ejecuta al final de cada vuelta). Es el bucle adecuado cuando sabes cuántas vueltas quieres dar. 
    for (let i = 1; i <= 5; i++) {
    console.log(`Vuelta número ${i}`);
}
// Vuelta número 1 ... Vuelta número 5
  • Contar hacia atrás o de otro modo: basta con cambiar la inicialización, la condición y la actualización. 
    for (let i = 10; i >= 0; i -= 2) {
    console.log(i); // 10, 8, 6, 4, 2, 0
}
  • Recorrer un array con su índice: el índice va de 0 a length - 1, por eso la condición usa < y no <=. 
    const frutas = ['manzana', 'pera', 'uva'];
for (let i = 0; i < frutas.length; i++) {
    console.log(`${i}: ${frutas[i]}`);
}
  • Acumuladores y contadores: son variables que se declaran antes del bucle y se actualizan en cada vuelta para sumar, contar o construir un resultado. 
    let total = 0;
for (let i = 1; i <= 4; i++) {
    total += i;
}
console.log(total); // 10 (1 + 2 + 3 + 4)

while y do...while

  • while: repite el bloque mientras la condición sea verdadera. Se usa cuando no sabes de antemano cuántas vueltas hacen falta. Si la condición es falsa desde el principio, no da ninguna vuelta. 
    let dinero = 100;
let meses = 0;
while (dinero < 200) {
    dinero *= 1.1; // crece un 10 % cada mes
    meses++;
}
console.log(`Se duplica en ${meses} meses`); // 8
  • do...while: comprueba la condición al final, así que el bloque se ejecuta al menos una vez. Es útil cuando primero hay que hacer algo y después decidir si se repite, como pedir un dato hasta que sea válido. 
    let edad;
do {
    edad = Number(prompt('¿Cuántos años tienes?'));
} while (Number.isNaN(edad) || edad < 0);
  • Bucles infinitos: si la condición nunca llega a ser falsa, el bucle no termina y la página se bloquea. Comprueba siempre que la variable de la condición cambia dentro del bucle. 
    let i = 0;
while (i < 5) {
    console.log(i);
    // Falta i++: i siempre vale 0 y el bucle no termina nunca
}

for...of y for...in

  • for...of: recorre directamente los valores de algo recorrible: un array, un string, un Set... Es la forma más clara cuando no necesitas el índice. 
    for (const fruta of ['manzana', 'pera', 'uva']) {
    console.log(fruta);
}
for (const letra of 'hola') {
    console.log(letra); // h, o, l, a
}
  • for...in: recorre las claves (nombres de las propiedades) de un objeto. 
    const persona = { nombre: 'Ana', edad: 28 };
for (const clave in persona) {
    console.log(`${clave}: ${persona[clave]}`);
}
// nombre: Ana
// edad: 28
  • No uses for...in con arrays: devuelve los índices como texto ('0', '1'...), no los valores. Para arrays usa for...of, un for clásico o los métodos de arrays.
  • Object.entries() con for...of: convierte un objeto en pares [clave, valor] que se pueden recorrer y desestructurar. 
    for (const [clave, valor] of Object.entries(persona)) {
    console.log(`${clave}: ${valor}`);
}

break y continue

  • break: termina el bucle en ese momento. Se usa, por ejemplo, para dejar de buscar cuando ya se ha encontrado lo que se buscaba. 
    const numeros = [4, 9, 15, 22, 8];
for (const n of numeros) {
    if (n > 10) {
        console.log(`El primero mayor que 10 es ${n}`); // 15
        break;
    }
}
  • continue: salta el resto de la vuelta actual y pasa directamente a la siguiente. 
    for (let i = 1; i <= 10; i++) {
    if (i % 3 === 0) {
        continue; // se salta los múltiplos de 3
    }
    console.log(i); // 1, 2, 4, 5, 7, 8, 10
}
  • return dentro de una función: sale del bucle y de la función a la vez.

Bucles anidados

  • Un bucle dentro de otro: por cada vuelta del bucle exterior, el interior da todas sus vueltas. Se usan para recorrer tablas, cuadrículas o combinaciones. 
    for (let fila = 1; fila <= 3; fila++) {
    let linea = '';
    for (let col = 1; col <= 3; col++) {
        linea += `${fila * col}\t`;
    }
    console.log(linea);
}
// 1  2  3
// 2  4  6
// 3  6  9
  • Nombres de variables distintos: cada bucle necesita su propia variable (fila y col, o i y j). Si usas la misma, el bucle interior modifica la del exterior.

¿Qué bucle elijo?

  • Sabes cuántas vueltas quieres dar o necesitas el índice: for.
  • Repetir mientras se cumpla una condición, sin saber cuántas vueltas: while.
  • Hacer algo al menos una vez y luego decidir si se repite: do...while.
  • Recorrer los valores de un array o un string: for...of.
  • Recorrer las propiedades de un objeto: for...in u Object.entries() con for...of.
  • Transformar, filtrar o sumar un array: muchas veces es más claro usar los métodos del tema de Arrays (map, filter, reduce, find...), que ya recorren el array por dentro. 
    const precios = [10, 20, 30];

// Con un bucle
const conIva = [];
for (const p of precios) {
    conIva.push(p * 1.21);
}

// Con un método de arrays: el mismo resultado en una línea
const conIva2 = precios.map(p => p * 1.21);

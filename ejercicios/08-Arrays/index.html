Arrays

Un array es una estructura de datos que permite almacenar múltiples valores en una sola variable. En JavaScript, los arrays son objetos especiales que pueden contener cualquier tipo de dato, incluyendo otros arrays.

Los arrays son útiles para almacenar colecciones de datos y se pueden manipular fácilmente utilizando métodos integrados.

Ejemplo de un array:

let frutas = ['manzana', 'banana', 'naranja'];
console.log(frutas[0]); // salida: 'manzana'

Los arrays en JavaScript son dinámicos, lo que significa que pueden crecer y decrecer según sea necesario. Puedes agregar o eliminar elementos de un array utilizando métodos como push(), pop(), shift(), y unshift().

Ejemplo de agregar y eliminar elementos:

let frutas = ['manzana', 'banana', 'naranja'];
frutas.push('uva'); // agrega 'uva' al final del array
console.log(frutas); // salida: ['manzana', 'banana', 'naranja', 'uva']

frutas.pop(); // elimina el último elemento del array
console.log(frutas); // salida: ['manzana', 'banana', 'naranja']

También puedes recorrer un array utilizando un bucle for o el método forEach().

Ejemplo de recorrer un array:

let frutas = ['manzana', 'banana', 'naranja'];
frutas.forEach(function(fruta) {
    console.log(fruta);
});

En este ejemplo, el método forEach() recorre cada elemento del array y ejecuta la función proporcionada para cada uno de ellos.

Ejemplo de recorrer un array utilizando un bucle for:

let frutas = ['manzana', 'banana', 'naranja'];
for (let i = 0; i < frutas.length; i++) {
    console.log(frutas[i]);
}

Los arrays también tienen propiedades útiles, como length, que devuelve la cantidad de elementos en el array.

Ejemplo de usar la propiedad length:

let frutas = ['manzana', 'banana', 'naranja'];
console.log(frutas.length); // salida: 3

Índices y acceso a los elementos

  • Índices: las posiciones empiezan en 0, así que el último elemento está en length - 1. Si accedes a una posición que no existe obtienes undefined. 
    let colores = ['rojo', 'verde', 'azul'];
console.log(colores[colores.length - 1]); // 'azul'
console.log(colores[5]); // undefined
  • at(): accede a una posición y admite índices negativos para contar desde el final. 
    console.log(colores.at(-1)); // 'azul'
console.log(colores.at(-2)); // 'verde'
  • Modificar un elemento: se asigna un nuevo valor a su posición. Funciona aunque el array se haya declarado con const, porque se cambia su contenido, no la variable. 
    const colores = ['rojo', 'verde', 'azul'];
colores[1] = 'amarillo'; // ['rojo', 'amarillo', 'azul']
// colores = []; // Error: no se puede reasignar una constante
  • Arrays anidados: un array puede contener otros arrays (matrices). Se accede con dos índices. 
    let tablero = [
    ['X', 'O', 'X'],
    ['O', 'X', 'O'],
];
console.log(tablero[1][0]); // 'O' (fila 1, columna 0)
  • Array.isArray(): comprueba si un valor es un array. typeof no sirve, porque devuelve 'object'. 
    console.log(typeof [1, 2]);        // 'object'
console.log(Array.isArray([1, 2])); // true

Métodos que modifican el array original

Estos métodos cambian el array sobre el que se llaman. Es la forma imperativa de trabajar que ves en la primera parte de js/app.js.

  • push() / unshift(): añaden elementos al final o al principio. Devuelven la nueva longitud. 
    let numeros = [2, 3];
numeros.push(4);    // [2, 3, 4]
numeros.unshift(1); // [1, 2, 3, 4]
  • pop() / shift(): eliminan el último o el primer elemento y lo devuelven. 
    let ultimo = numeros.pop();   // 4, numeros = [1, 2, 3]
let primero = numeros.shift(); // 1, numeros = [2, 3]
  • splice(posición, cuántos, ...nuevos): elimina, inserta o sustituye elementos en cualquier posición. 
    let letras = ['a', 'b', 'c', 'd'];
letras.splice(1, 2);           // elimina 'b' y 'c' → ['a', 'd']
letras.splice(1, 0, 'x', 'y'); // inserta en la posición 1 → ['a', 'x', 'y', 'd']
  • sort(): ordena el array. ¡Cuidado! Sin argumentos compara los elementos como texto, así que con números hay que pasar una función comparadora. 
    let nums = [10, 1, 25, 3];
nums.sort();                // [1, 10, 25, 3]  (orden de texto)
nums.sort((a, b) => a - b); // [1, 3, 10, 25]  (menor a mayor)
nums.sort((a, b) => b - a); // [25, 10, 3, 1]  (mayor a menor)
  • reverse(): invierte el orden de los elementos. 
    [1, 2, 3].reverse(); // [3, 2, 1]

Métodos que devuelven un array nuevo

No tocan el original: crean y devuelven un array nuevo. Es la forma declarativa, la que se usa en la segunda parte de js/app.js y la que conviene preferir, porque evita cambios inesperados en datos que se usan en otras partes del código.

  • slice(inicio, fin): copia una porción del array (el elemento de la posición fin no se incluye). 
    let letras = ['a', 'b', 'c', 'd'];
letras.slice(1, 3); // ['b', 'c']
letras.slice();     // copia completa
  • Spread (...) y concat(): copian o unen arrays. 
    let a = [1, 2];
let b = [3, 4];
let unidos = [...a, ...b];   // [1, 2, 3, 4]
let conExtra = [0, ...a, 5]; // [0, 1, 2, 5]
let concatenados = a.concat(b); // [1, 2, 3, 4]
  • toSorted(), toReversed(), toSpliced() y with() (ES2023): versiones de sort(), reverse() y splice() que no modifican el original. with() devuelve una copia con un elemento cambiado. 
    let nums = [3, 1, 2];
let ordenados = nums.toSorted((a, b) => a - b); // [1, 2, 3]
let cambiado = nums.with(0, 99);               // [99, 1, 2]
console.log(nums); // [3, 1, 2] → el original no cambia

Buscar elementos

  • includes(): indica si el array contiene un valor. 
    ['ana', 'luis'].includes('luis'); // true
  • indexOf(): devuelve la posición de un valor o -1 si no está. 
    ['ana', 'luis'].indexOf('luis'); // 1
['ana', 'luis'].indexOf('eva');  // -1
  • find() / findIndex(): buscan el primer elemento que cumple una condición y devuelven el elemento (o undefined) o su posición (o -1). Son los que se usan con arrays de objetos. 
    let productos = [
    { nombre: 'Tablet', precio: 300 },
    { nombre: 'Monitor', precio: 500 },
];
productos.find(p => p.precio > 400);      // { nombre: 'Monitor', precio: 500 }
productos.findIndex(p => p.precio > 400); // 1
  • findLast() / findLastIndex() (ES2023): igual que los anteriores, pero empiezan a buscar por el final. 
    [5, 12, 8, 20].findLast(n => n > 10); // 20
  • some() / every(): comprueban si al menos uno o todos los elementos cumplen una condición. Devuelven un booleano. 
    let notas = [7, 4, 9];
notas.some(n => n < 5);  // true  (hay algún suspenso)
notas.every(n => n >= 5); // false (no han aprobado todos)

Recorrer y transformar

  • for...of: recorre directamente los valores, sin necesidad de índice. 
    for (const fruta of ['manzana', 'pera']) {
    console.log(fruta);
}
  • map(): crea un array nuevo aplicando una función a cada elemento. El resultado tiene la misma longitud que el original. 
    let precios = [10, 20, 30];
let conIva = precios.map(p => p * 1.21); // [12.1, 24.2, 36.3]
  • filter(): crea un array nuevo solo con los elementos que cumplen una condición. 
    let numeros = [1, 2, 3, 4, 5, 6];
let pares = numeros.filter(n => n % 2 === 0); // [2, 4, 6]
  • reduce(función, valorInicial): recorre el array acumulando un único resultado (una suma, un total, un objeto...). 
    let carrito = [
    { nombre: 'Camiseta', precio: 15 },
    { nombre: 'Pantalón', precio: 35 },
];
let total = carrito.reduce((acumulado, p) => acumulado + p.precio, 0); // 50
  • Encadenar métodos: como filter() y map() devuelven arrays, se pueden encadenar. 
    let baratos = productos
    .filter(p => p.precio < 400)
    .map(p => p.nombre); // ['Tablet']
  • join() y split(): convierten un array en texto y viceversa. 
    ['a', 'b', 'c'].join('-'); // 'a-b-c'
'a-b-c'.split('-');        // ['a', 'b', 'c']
  • flat(): aplana arrays anidados. 
    [1, [2, 3], [4]].flat(); // [1, 2, 3, 4]

Desestructuración, Set y agrupación

  • Desestructuración: extrae elementos en variables. Con ... se recoge el resto. 
    let [primero, segundo, ...resto] = [10, 20, 30, 40];
// primero = 10, segundo = 20, resto = [30, 40]
  • Eliminar duplicados con Set: un Set no admite valores repetidos; con spread se vuelve a convertir en array. 
    let repetidos = [1, 2, 2, 3, 3, 3];
let unicos = [...new Set(repetidos)]; // [1, 2, 3]
  • Array.from(): crea un array a partir de cualquier cosa recorrible (un texto, un Set...) o de una longitud. 
    Array.from('hola');                  // ['h', 'o', 'l', 'a']
Array.from({ length: 3 }, (_, i) => i); // [0, 1, 2]
  • Object.groupBy() (ES2024): agrupa los elementos en un objeto según el valor que devuelva la función. 
    let productos = [
    { nombre: 'Sartén', categoria: 'hogar' },
    { nombre: 'Novela', categoria: 'libros' },
    { nombre: 'Lámpara', categoria: 'hogar' },
];
let grupos = Object.groupBy(productos, p => p.categoria);
// { hogar: [Sartén, Lámpara], libros: [Novela] }

Novedades de ECMAScript 2026

La última edición del estándar, aprobada en junio de 2026, incluye dos novedades relacionadas con arrays. Son muy recientes: antes de usarlas en un proyecto real, comprueba en MDN que los navegadores a los que te diriges las admiten.

  • Math.sumPrecise(): suma todos los números de un array sin ir perdiendo precisión por el camino. Con reduce(), al sumar números de tamaños muy distintos, los pequeños pueden "desaparecer". 
    [1e20, 0.1, -1e20].reduce((a, b) => a + b, 0); // 0   (se ha perdido el 0.1)
Math.sumPrecise([1e20, 0.1, -1e20]);           // 0.1

// Ojo: no arregla la representación de los decimales
Math.sumPrecise([0.1, 0.2]); // 0.30000000000000004
  • Array.fromAsync(): como Array.from(), pero para datos que llegan de forma asíncrona. Lo usarás cuando veas promesas y async/await.

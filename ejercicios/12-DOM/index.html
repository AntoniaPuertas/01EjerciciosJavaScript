DOM

Cuando el navegador carga una página, convierte el HTML en un árbol de objetos llamado DOM (Document Object Model). Cada etiqueta es un nodo del árbol, y JavaScript puede leerlos y modificarlos.

Gracias al DOM, JavaScript puede cambiar textos, estilos y atributos, crear elementos nuevos o eliminarlos, y la página se actualiza al momento sin tener que recargarla.

El árbol del DOM

  • Nodos padre e hijos: cada elemento está dentro de otro (su padre) y puede contener otros (sus hijos). Los elementos que comparten padre son hermanos. En lo más alto está el objeto document, que representa toda la página. 
    <body>                      document
  <h1>Tienda</h1>             └── html
  <ul>                            └── body
    <li>Pan</li>                     ├── h1  ("Tienda")
    <li>Leche</li>                   └── ul
  </ul>                                 ├── li  ("Pan")
</body>                                 └── li  ("Leche")

Seleccionar elementos

  • querySelector(): devuelve el primer elemento que coincide con un selector CSS, o null si no encuentra ninguno. Admite cualquier selector de CSS. 
    const titulo = document.querySelector('h1');
const menu = document.querySelector('#menu');           // por id
const aviso = document.querySelector('.aviso');         // por clase
const enlace = document.querySelector('nav a:first-child');
  • querySelectorAll(): devuelve todos los elementos que coinciden, en una NodeList. Se puede recorrer con forEach o for...of y tiene length. Si no hay ninguno, devuelve una lista vacía. 
    const productos = document.querySelectorAll('.producto');
console.log(productos.length);
productos.forEach(producto => console.log(producto.textContent));
  • getElementById(): busca por id, sin la #. Es más antiguo pero muy habitual. 
    const menu = document.getElementById('menu');
  • Buscar dentro de un elemento: querySelector y querySelectorAll también funcionan sobre cualquier elemento, y entonces solo buscan dentro de él. 
    const lista = document.querySelector('#carrito');
const articulos = lista.querySelectorAll('li');
  • Si devuelve null: el selector no coincide con nada. Es la causa del error más habitual del DOM: Cannot read properties of null. Revisa el selector (# para id, . para clase) y que el elemento exista cuando se ejecuta el script.

Leer y cambiar el contenido

  • textContent: lee o cambia el texto de un elemento. Si el texto contiene etiquetas, se muestran tal cual, sin interpretarlas. Es la opción recomendada para mostrar texto. 
    const saludo = document.querySelector('#saludo');
saludo.textContent = 'Hola, Ana';
saludo.textContent = '<b>Hola</b>'; // se ve literalmente: <b>Hola</b>
  • innerHTML: lee o cambia el contenido interpretándolo como HTML. 
    saludo.innerHTML = 'Hola, <strong>Ana</strong>'; // "Ana" aparece en negrita
  • Cuidado con innerHTML: nunca lo uses con datos escritos por un usuario (un formulario, un comentario...). Si el texto contiene código malicioso, el navegador lo ejecutaría. A este ataque se le llama XSS. Para mostrar datos de usuarios, usa textContent o crea los elementos con createElement. 
    const comentario = '<img src="x" onerror="alert(\'¡Te he hackeado!\')">';
caja.innerHTML = comentario;   // ¡peligroso: se ejecuta el código!
caja.textContent = comentario; // seguro: se muestra como texto
  • Novedad: setHTML(): los navegadores están incorporando setHTML(), que inserta HTML eliminando automáticamente las partes peligrosas. Firefox (desde la versión 148) y Chrome (desde la 146) ya la incluyen, pero Safari todavía no, así que aún no conviene usarla sin comprobar antes que existe. 
    if ('setHTML' in Element.prototype) {
    caja.setHTML(comentario); // inserta la imagen sin el onerror
}

Atributos

  • getAttribute() y setAttribute(): leen y cambian cualquier atributo. removeAttribute() lo elimina. 
    const enlace = document.querySelector('a');
console.log(enlace.getAttribute('href'));
enlace.setAttribute('href', 'https://developer.mozilla.org/es/');
enlace.removeAttribute('title');
  • Propiedades directas: los atributos más comunes también se pueden usar como propiedades del elemento. 
    enlace.href = 'https://developer.mozilla.org/es/';
enlace.target = '_blank';
imagen.alt = 'Logotipo del curso';
campo.value = 'Texto inicial'; // en inputs
  • Atributos data-* y dataset: los atributos que empiezan por data- sirven para guardar datos propios en el HTML. Se leen y cambian con dataset, quitando el prefijo data- y escribiendo en camelCase. Su valor siempre es texto. 
    // <li data-id="42" data-precio-oferta="9.99">Libro</li>
const libro = document.querySelector('li');
console.log(libro.dataset.id);            // '42'
console.log(libro.dataset.precioOferta);  // '9.99' (data-precio-oferta)
libro.dataset.stock = '5';                // añade data-stock="5"

Estilos y clases

  • style: cambia estilos en línea. Las propiedades con guion se escriben en camelCase: background-color pasa a ser backgroundColor. 
    const caja = document.querySelector('.caja');
caja.style.backgroundColor = 'gold';
caja.style.fontSize = '1.5rem';
  • classList: añade, quita o alterna clases. toggle pone la clase si no está y la quita si está; contains comprueba si la tiene. 
    caja.classList.add('activa');
caja.classList.remove('oculta');
caja.classList.toggle('seleccionada');
console.log(caja.classList.contains('activa')); // true
  • Mejor clases que style: define los estilos en el CSS y usa JavaScript solo para añadir o quitar clases. Así el diseño queda en un solo sitio, es más fácil de cambiar y se adapta a los temas claro y oscuro. Usa style para valores que se calculan en el momento, como una posición o un tamaño.

Crear, insertar y eliminar elementos

  • createElement(): crea un elemento nuevo. Existe en memoria, pero no aparece en la página hasta que se inserta. 
    const nuevo = document.createElement('li');
nuevo.textContent = 'Huevos';
nuevo.classList.add('producto');
  • Insertar: append() añade al final del elemento y prepend() al principio; before() y after() lo colocan fuera, delante o detrás. Todos admiten varios elementos o textos a la vez. 
    const lista = document.querySelector('#compra');
lista.append(nuevo);                 // último de la lista
lista.prepend(otro);                 // primero de la lista
lista.before(titulo);                // justo antes de la lista, fuera de ella
lista.append(elemento1, elemento2);  // varios a la vez
  • Eliminar: remove() quita el elemento de la página. replaceChildren() sin argumentos vacía un elemento por completo. 
    document.querySelector('.aviso').remove();
lista.replaceChildren(); // la lista se queda vacía
  • Construir antes de insertar: cada vez que se inserta algo en la página, el navegador la redibuja. Si vas a crear muchos elementos, prepáralos primero y añádelos todos de una vez. 
    const frutas = ['Pera', 'Uva', 'Kiwi'];
const elementos = frutas.map(fruta => {
    const li = document.createElement('li');
    li.textContent = fruta;
    return li;
});
lista.append(...elementos); // una sola inserción

Moverse por el árbol

  • Desde un elemento se puede llegar a sus vecinos sin volver a buscar en todo el documento. 
    elemento.parentElement           // el padre
elemento.children                // sus hijos (HTMLCollection)
elemento.firstElementChild       // primer hijo
elemento.lastElementChild        // último hijo
elemento.previousElementSibling  // hermano anterior
elemento.nextElementSibling      // hermano siguiente
  • closest(): sube por los antepasados del elemento y devuelve el primero que coincide con un selector. Será muy útil en el tema de Eventos. 
    const boton = document.querySelector('.tarjeta button');
const tarjeta = boton.closest('.tarjeta'); // la tarjeta que contiene el botón
  • Element frente a Node: propiedades como childNodes, firstChild o nextSibling también devuelven los nodos de texto, incluidos los saltos de línea del HTML. Usa las versiones con Element en el nombre para trabajar solo con etiquetas.

Cuándo se ejecuta el script

  • El HTML se lee de arriba abajo: si un script se ejecuta antes de que exista un elemento, no lo encontrará. Hay dos soluciones habituales: 
    <!-- 1. Al final del body, como en este curso -->
    <script src="js/app.js"></script>
</body>

<!-- 2. En el head con defer: se descarga a la vez pero espera a que el HTML esté listo -->
<head>
    <script src="js/app.js" defer></script>
</head>

Buenas prácticas

  • Guarda en una variable los elementos que vayas a usar varias veces, en lugar de buscarlos cada vez.
  • Usa textContent para mostrar texto, y reserva innerHTML para HTML que hayas escrito tú.
  • Cambia clases en lugar de estilos sueltos.
  • Crea funciones que construyan los elementos repetidos (una tarjeta, una fila de tabla...) a partir de sus datos.

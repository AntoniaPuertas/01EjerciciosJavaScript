Funciones

Una función es un bloque de código con nombre que realiza una tarea concreta. Se escribe una vez y se puede ejecutar (llamar) tantas veces como haga falta, con datos distintos cada vez.

Las funciones permiten organizar el código en piezas pequeñas, evitar repeticiones y darle un nombre a cada tarea para que el programa se entienda mejor.

Declarar y llamar una función

  • Declaración y llamada: se declara con function, un nombre y unos paréntesis. Declararla no la ejecuta: hay que llamarla escribiendo su nombre seguido de paréntesis. 
    function mostrarBienvenida() {
    console.log('¡Bienvenido al curso!');
}

mostrarBienvenida(); // ¡Bienvenido al curso!
mostrarBienvenida(); // se puede llamar las veces que haga falta
  • Parámetros y argumentos: los parámetros son las variables que aparecen en la declaración; los argumentos son los valores concretos que se pasan al llamarla. 
    function saludar(nombre, curso) {  // nombre y curso son parámetros
    console.log(`Hola, ${nombre}. Bienvenido a ${curso}`);
}

saludar('Ana', 'JavaScript'); // 'Ana' y 'JavaScript' son argumentos
  • return: devuelve un resultado a quien llamó a la función y la termina en ese momento. El código que haya después no se ejecuta. 
    function sumar(a, b) {
    return a + b;
    console.log('Esto no se ejecuta nunca');
}

const resultado = sumar(3, 4);
console.log(resultado); // 7
  • Sin return: una función que no tiene return devuelve undefined. Mostrar algo con console.log() no es lo mismo que devolverlo. 
    function mostrarDoble(n) {
    console.log(n * 2);
}

const valor = mostrarDoble(5); // muestra 10
console.log(valor);            // undefined: la función no devolvió nada

Tres formas de crear funciones

  • Declaración de función: la forma clásica. Se puede llamar incluso antes de la línea donde está escrita, porque JavaScript la "sube" al principio (a esto se le llama hoisting). 
    console.log(cuadrado(4)); // 16: funciona aunque esté declarada más abajo

function cuadrado(n) {
    return n * n;
}
  • Expresión de función: la función se guarda en una variable. Solo se puede usar después de esa línea. 
    const cubo = function (n) {
    return n * n * n;
};

console.log(cubo(2)); // 8
  • Función flecha: una forma más corta de escribir expresiones de función. Si el cuerpo es una sola expresión, se pueden quitar las llaves y el return. Con un solo parámetro, también los paréntesis. 
    const sumar = (a, b) => a + b;
const doble = n => n * 2;
const saludo = () => 'Hola';

// Con varias líneas se necesitan llaves y return
const precioConIva = (precio) => {
    const iva = precio * 0.21;
    return precio + iva;
};
  • Devolver un objeto con una flecha: hay que rodearlo de paréntesis; si no, JavaScript confunde las llaves del objeto con las del cuerpo de la función. 
    const crearPunto = (x, y) => ({ x, y });
console.log(crearPunto(2, 5)); // { x: 2, y: 5 }
  • Flechas y this: las funciones flecha no tienen su propio this. Por eso, para los métodos de un objeto se usa la sintaxis de método normal. 
    const persona = {
    nombre: 'Ana',
    saludar() { return `Soy ${this.nombre}`; },      // correcto
    saludarFlecha: () => `Soy ${this.nombre}`,       // this no es persona
};
console.log(persona.saludar()); // Soy Ana

Parámetros

  • Argumentos que faltan o sobran: si se pasan menos argumentos, los parámetros que faltan valen undefined. Si se pasan más, se ignoran. 
    function presentar(nombre, edad) {
    return `${nombre} tiene ${edad} años`;
}
console.log(presentar('Luis')); // Luis tiene undefined años
  • Valores por defecto: se usan cuando el argumento no se pasa. 
    function presentar(nombre, edad = 18) {
    return `${nombre} tiene ${edad} años`;
}
console.log(presentar('Luis'));     // Luis tiene 18 años
console.log(presentar('Luis', 25)); // Luis tiene 25 años
  • Parámetro rest (...): reúne en un array todos los argumentos restantes. Permite crear funciones que aceptan cualquier cantidad de valores. Solo puede haber uno y tiene que ir al final. 
    function mayor(...numeros) {
    return Math.max(...numeros);
}
console.log(mayor(3, 9, 4));        // 9
console.log(mayor(10, 2, 35, 7, 1)); // 35
  • Un objeto como parámetro: cuando una función necesita muchos datos, es más claro pasar un objeto y desestructurarlo. Así el orden de los argumentos no importa. 
    function crearUsuario({ nombre, email, rol = 'alumno' }) {
    return `${nombre} (${email}) - ${rol}`;
}
console.log(crearUsuario({ email: 'ana@ejemplo.com', nombre: 'Ana' }));
// Ana (ana@ejemplo.com) - alumno

Ámbito de las variables

  • Ámbito (scope): es la zona del código donde una variable existe y se puede usar. Las variables declaradas dentro de una función son locales: no se ven desde fuera. 
    function calcular() {
    const secreto = 42;
    console.log(secreto); // 42
}
calcular();
console.log(secreto); // ReferenceError: secreto is not defined
  • Ámbito de bloque: let y const solo existen dentro de las llaves donde se declaran (un if, un bucle...). 
    if (true) {
    const mensaje = 'dentro';
}
console.log(mensaje); // ReferenceError
  • Desde dentro se ve lo de fuera: una función puede leer las variables del ámbito que la rodea, pero no al revés. Aun así, es mejor que una función reciba lo que necesita por parámetro en lugar de depender de variables globales.

Funciones como valores

  • Callbacks: en JavaScript una función es un valor más, así que se puede pasar como argumento a otra función. Ya lo has hecho con forEach, map o filter. Para pasarla se escribe su nombre sin paréntesis. 
    const esPar = n => n % 2 === 0;
console.log([1, 2, 3, 4].filter(esPar)); // [2, 4]
// filter(esPar()) sería un error: pasaría el resultado, no la función
  • Funciones que devuelven funciones: una función puede crear y devolver otra función. 
    function crearSaludo(saludo) {
    return nombre => `${saludo}, ${nombre}`;
}
const saludoFormal = crearSaludo('Buenos días');
console.log(saludoFormal('Sra. López')); // Buenos días, Sra. López
  • Closures: la función devuelta "recuerda" las variables del lugar donde se creó, aunque la función que la creó ya haya terminado. En el ejemplo anterior, saludoFormal sigue recordando 'Buenos días'. Sirven, por ejemplo, para crear datos privados que solo se pueden cambiar a través de ciertas funciones.

Recursividad

  • Una función que se llama a sí misma: resuelve un problema dividiéndolo en versiones más pequeñas del mismo problema. Siempre necesita un caso base que detenga las llamadas; sin él, la función se llamaría sin fin y el navegador daría un error. 
    function cuentaAtras(n) {
    if (n === 0) {           // caso base
        console.log('¡Despegue!');
        return;
    }
    console.log(n);
    cuentaAtras(n - 1);      // llamada recursiva con un problema más pequeño
}
cuentaAtras(3); // 3, 2, 1, ¡Despegue!

Buenas prácticas

  • Nombres con verbo que digan lo que hace la función: calcularTotal, validarEmail, mostrarError. Si devuelve un booleano, suele empezar por es o tiene: esPar, tieneStock.
  • Una función, una tarea: si al describirla necesitas decir "y además...", probablemente conviene dividirla en dos.
  • Funciones puras: siempre que puedas, escribe funciones que, con los mismos argumentos, devuelvan siempre el mismo resultado y no modifiquen nada de fuera (variables globales, arrays u objetos recibidos). Son más fáciles de probar y de entender. 
    // Impura: modifica el array que recibe
function anadirImpura(lista, elemento) {
    lista.push(elemento);
}

// Pura: devuelve un array nuevo y no toca el original
const anadir = (lista, elemento) => [...lista, elemento];
  • Cláusulas de guarda: comprueba al principio los casos no válidos y sal con return, como viste en el tema de Condicionales.
  • Documenta las funciones importantes con un comentario JSDoc. Editores como VS Code lo muestran al escribir la llamada. 
    /**
 * Calcula el precio con IVA.
 * @param {number} precio - Precio sin IVA.
 * @param {number} [iva=21] - Porcentaje de IVA.
 * @returns {number} Precio con IVA.
 */
function conIva(precio, iva = 21) {
    return precio * (1 + iva / 100);
}
